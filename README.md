# Name2DateFixer
Name2DateFixer 是一个基于 PowerShell 的开源工具，旨在利用 ExifTool，通过照片/视频的文件名智能找回丢失的 EXIF 拍摄日期。

**数据无价，谨慎操作**。

## 为什么需要 Name2DateFixer?
当我们将照片备份到云端再重新下载时，记载着照片时间的**元数据**可能会丢失，导致照片的**创建时间**变成了**下载日期**。

但我们认为，时间不只是一个属性，它是照片记忆的主要组成部分。因此，我们编写了这个脚本，**将失去的时间，还给照片**。

## Name2DateFixer 的工作方式?
1. 复制全部照片到输出目录 Output.
2. 检查文件是否已包含有效的 EXIF 日期标签，有则直接跳过。
3. 无有效日期则尝试从文件名提取日期时间。
4. 若文件名没有日期时间信息，再尝试提取 Unix 时间戳并写入。
5. 以上推测全部失败，移动到复核目录 Review.

对工作目录 Input 的所有操作都在复制后进行。最大限度保障数据安全。

支持多级目录遍历，不破坏原目录结构。

## 如何使用 Name2DateFixer？
### 下载并配置 ExifTool
1. 前往 [ExifTool 官网](https://exiftool.org/) 下载Windows 版本的 ```.zip``` 包。
2. 解压后，将 ```exiftool(-k).exe``` 重命名为 ```exiftool.exe```.
3. 将该文件所在的路径添加到系统的 **环境变量** 中。
### 下载并使用 Name2DateFixer
1. 下载本项目中的 ```Name2DateFixer.ps1```.
2. 右键点击脚本 -> 选择 “使用 PowerShell 运行”。
3. 脚本会自动在同级目录下创建工作文件夹。将待处理的照片放入指定目录即可。

## 工作细节

### 有效日期判定规则：
脚本会用 ExifTool 读取以下字段：

```DateTimeOriginal```

```CreateDate```

```ModifyDate```

```MediaCreateDate```

```TrackCreateDate```

### 文件名识别方式：
脚本会对去掉扩展名后的文件名进行匹配，优先尝试“带时分秒”的完整日期，其次尝试“仅日期（当天 00:00:00）”。

#### 时分秒
支持示例（只要文件名中包含以下结构即可，不要求全文完全一致）：
1. 2024-01-02-15-30-45
2. 20240102_153045
3. 20240102153045
4. 20240102-153045 或 20240102_153045
5. 2024_01_02_15_30_45（也支持 -/_ 混合分隔）
6. 2024-01-02 15.30.45 或 2024-01-02.15.30.45（空格/点号组合）

#### 仅日期（时间写为 00:00:00）
1. 20240102
2. 2024-01-02
3. 2024_01_02

### 从文件名提取 Unix 时间戳（13 位毫秒）
若文件名中包含 13 位数字，且范围在：```946684800000```（约 2000-01-01） ~ ```4102444800000```（约 2100-01-01）

脚本会将其视为 Unix 毫秒时间戳。

### 元数据标签的写入方式：

#### 图片格式写入：

```DateTimeOriginal```

```CreateDate```

```ModifyDate```

##### .gif .png .bmp .webp 格式额外写入：

```FileModifyDate```

```FileCreateDate```

#### 视频格式写入：

```AllDates```

```TrackCreateDate```

```MediaCreateDate```
